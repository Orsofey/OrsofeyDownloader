# Changelog

## 1.0.1 — 2026-11-25

### Исправления

- Включён принудительный вывод прогресса `yt-dlp` во всех фоновых процессах Windows и Android.
- Убрано жёсткое требование аудиодорожки M4A: теперь выбирается доступная рабочая альтернатива.
- Исправлен выбор формата YouTube при ошибках HTTP 503 отдельных аудиопотоков.
- HTTP 503 больше не отображается как «видео удалено»; показывается временная ошибка сервера.
- После добавления ссылки приложение автоматически открывает очередь загрузок.

## 1.0.0 — 2026-11-24

- Первая версия Orsofey Downloader для Windows и Android.
- YouTube, TikTok и VK Видео, плейлисты, MP3, субтитры, обложки, очередь, история и cookies.
